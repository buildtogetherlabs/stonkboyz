# Stonkboyz landing

NFT mint landing for the Stonkboyz character. The mint is on **OpenSea**, not this site.

**Live:** https://buildtogetherlabs.github.io/stonkboyz/mint/

- Supply **2,222**
- Price and mint date stay **TBA** until set in `CFG` in `index.html`
- **Mint on OpenSea** stays disabled until `CFG.opensea` is the drop URL
- Album cover + `assets/stonkboysforever.mp3` on the radio widget
- Lineup thumbnails are a 12-image subset of the final collection in `assets/lineup/`
